# UF4DigitalPower
修改当前的工程以适应新的系统参数和控制结构，确保电压和电流采样的准确性，并实现基于SPI的Flash数据存储和TVLCOM_V2_FULL串口通信功能。

系统参数：

输出范围：0.5–44V，0–10A
控制结构：电压环 + 电流环（双闭环 PID）

采样与量化：

电压采样（输入/输出相同方式）：
电压经 1/13.5135 分压进入 ADC
实际电压 = ADC 电压 × 13.5135
需要软件还原真实电压值

电流采样：
分流电阻：8mΩ
运放增益：20
中点偏置：1.65V
电流范围：±10A → ADC范围约 1.65V ±1.6V（≈0.05V–3.25V）
需进行零点校准与双向电流换算



PWM与拓扑映射：
输入端A
A1 → L1（低边1）
A2 → H1（高边1）

输出端D
D1 → L2（低边2）
D2 → H2（高边2）

支持互补输出与死区控制（Dead Time）

使用spi对flash进行数据存储，保存PID参数和系统状态，以便在重启后恢复。
使用TVLCOM_V2_FULL进行串口通信，提供实时数据监控和参数调整接口。

## 当前实现说明

- ADC 换算参数集中在 `APP/Inc/uf4_power_cfg.h`，电压按 `ADC电压 x 13.5135` 还原，电流按 `8mΩ x 20倍 + 1.65V偏置` 进行双向换算。
- 输出设定范围由固件限制为 `0.5-44V`、`0-10A`，串口写入超出范围时会被钳位。
- W25Q64 Flash 保存输出电压、电流、OTP、OCP、OVP 等设定；设定被串口修改后通过现有 `Update_Flash()` 流程落盘。
- TVLCOM 通信契约见 `COMMUNICATION_COMMANDS.md`；固件侧入口为 `UF4_TvlcomProcess()`，当前接在主循环中处理 USART1 上位机帧。
